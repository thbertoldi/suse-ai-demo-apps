# SUSE AI Demo Apps 0.2.0

This release consolidates the native AI observability demo into versioned images
and a Helm chart. The default install uses Milvus and Ollama; all external
products and the OpenTelemetry Collector must already be installed.

- Retains the merged GenAI usage/error metrics, standard content capture,
  Open WebUI traffic, database endpoint spans and native pod identity.
- Aligns generation and embedding endpoints across traces and metrics so model
  usage charts and trace links refer to the same destination.
- Adds Secret-based inference authentication, OpenSearch CA mounting and Lucene
  indexing, and separate Qdrant/OpenSearch RAG deployments.
- Packages selectable vLLM, LiteLLM, Qdrant, OpenSearch, MLflow and mcpo traffic
  in the RAG image. Bounded scenario Jobs return failure when a scenario fails.
- Adds a CPU PyTorch training image/CronJob with verified MLflow checkpoint
  upload/download and OTLP metrics/traces.
- Makes Kubeflow traffic and RBAC opt-in. Existing lifecycle deployments must
  include `examples/kubeflow.yaml` when upgrading.
- Adds PR regression checks, seven image builds/runtime smoke checks, chart
  packaging, checksum generation and a gated draft-release workflow.

The compatibility baseline is extension 3.0.0 and Collector 0.165.0. Images target
linux/amd64. Image tags default to chart `appVersion`; explicit digest overrides
are supported. OTel `service.namespace` now defaults to the Helm namespace; set
`otel.serviceNamespace` explicitly to retain an existing logical namespace.

Install the attached `suse-ai-demo-0.2.0.tgz` with your endpoint values. See the
repository README for model provisioning, credentials, optional profiles and
acceptance commands. Download the chart and `SHA256SUMS` together and run
`sha256sum -c SHA256SUMS` before installation.
